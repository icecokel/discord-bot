# 관리자 AI 디스코드 봇 컨셉

맥미니에서 실행되는 디스코드 봇은 관리자 기능과 정기 알림을 담당한다. 현재 일정, 관리자 명령어, 입력별 처리 규칙은 [README](../README.md)를 기준으로 한다.

## 역할

- `discord.js` 봇은 Discord 입력의 권한을 확인하고, 관리자 명령어와 스케줄러를 실행하며, 최종 응답을 전송한다.
- 관리자 DM의 일반 메시지는 Claude Messages API로 전달해 대화 맥락을 이어간다. `/질문`은 별도의 단발 AI 응답이다.
- Claude는 제공된 자료에 대한 답변을 담당하며 웹·파일·터미널 도구는 제공하지 않는다. Discord 메시지 전송·삭제·채널 관리 도구는 제공하지 않는다.
- 일반 사용자 DM과 서버 채널의 일반 메시지는 관리자 AI로 전달하지 않는다. `!클로드`는 기본 제어 명령이며 `!코덱스`, `!헤르메스`는 Claude 제어 호환 alias로 남아 있다.

Claude API와 오류 처리 구조는 [provider 문서](claude-api-provider.md)에, 위험 작업 처리 기준은 [AI 사용 지침](ai-guidelines.md)에 정리한다. 맥미니의 설정·배포·상태 확인은 [운영 서버 가이드](mac-mini-deployment.md)를 따른다.
